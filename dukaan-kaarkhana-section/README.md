# Dukaan & Kaarkhana — Two Tracks Section

This folder contains the complete code and assets for the **Two Tracks** section of the Dhandha School website.

## Contents

| File | Description |
|------|-------------|
| `tracks-section.jsx` | React JSX markup for the entire section |
| `tracks-section.css` | All CSS styles (base cards + decorative frame wrappers) |
| `dukaan_frame.png` | Traditional Indian shop frame image (golden/amber) |
| `kaarkhana_frame.png` | Industrial factory frame image (steel/red) |

## How to Use

1. **Images** → Copy `dukaan_frame.png` and `kaarkhana_frame.png` into your `public/` folder.
2. **CSS** → Import or paste the contents of `tracks-section.css` into your main stylesheet.
3. **JSX** → Paste the JSX from `tracks-section.jsx` into your React component where you want the section to appear.

## Fonts Required

- `Plus Jakarta Sans` — body text
- `Geist` — track titles
- `JetBrains Mono` — week badges (W1, W2, etc.)
